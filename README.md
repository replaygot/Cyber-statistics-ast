# Статистика загрузки компьютерных клубов Астаны

Раз в час открываем страницу онлайн-бронирования клуба и записываем, сколько мест занято
в общем зале и в буткемпе. Через неделю по этим данным пересчитываем модель выручки.

Сейчас идёт первый этап — разведка: `discover/discover.py` открывает
[страницу бронирования LORAN](https://booking.langame.ru/1jelye8o) на серверах GitHub
и сохраняет, откуда она берёт данные о местах. Результат лежит в ветке `discovery-output`.
