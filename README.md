# Статистика загрузки компьютерных клубов Астаны

Каждый час на 40-й минуте GitHub Actions спрашивает у сервиса онлайн-бронирования Langame,
какие места клуба заняты в ближайший час, и сохраняет ответ. Сбор идёт до 13 ноября 2026, 12:00.

**Смотреть результат:** [загрузка LORAN по часам](data/1jelye8o/SUMMARY.md)

## Что где лежит

- `data/<код клуба>/SUMMARY.md` — таблица загрузки по дням и часам и среднее по зонам.
- `data/<код клуба>/occupancy.csv` — все замеры: по строке на зону (Main, Bootcamp) и итог «ВСЕ».
  - `occupied` — занято: идёт сессия (`busy`) или место забронировано на этот час (`booked`);
  - `unavailable` — компьютер выключен или на обслуживании, занятым не считается;
  - `busy_seats`, `booked_seats` — номера мест.
- `data/<код клуба>/raw/` — полные ответы сервиса: там же время окончания текущих сессий и будущие брони.
- `collector/collect.py` — сбор, `collector/build.py` — пересборка таблиц из `raw/`.
- `.github/workflows/collect.yml` — расписание. Чтобы следить за другим клубом, добавь код
  из его ссылки `booking.langame.ru/<код>` в `CLUBS` через пробел.

Занятым считается место, на которое в ближайшие 60 минут нельзя оформить бронь,
кроме выключенных: так же это определяет сама страница бронирования.
